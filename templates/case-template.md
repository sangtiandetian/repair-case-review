# 案例卡模板

## 单张案例卡

```markdown
# 案例 {编号}：{板型} · {故障现象一句话}

- 日期：{YYYY-MM-DD}
- 板型/设备：{ }
- 现象分类：{不开机 / 无显示 / 反复重启 / 掉电 / 充电异常 / 接口失效 / 其他}
- 所属阶段：{如 第1关·电压测量}
- 结果：{修复 / 定位未修 / 未定位}

## 现象（原话）
{用户原始描述，照抄}

## 检测路径
| 步骤 | 测点 | 档位 | 红笔 | 黑笔 | 读数 | 当时判断 |
|---|---|---|---|---|---|---|
| 1 |  |  |  |  |  |  |

## 关键转折点
{第×步：这步之前以为是×，之后转向×}

## 根因（复盘整理）
{与已测读数一致的结论；证据不足时写“尚未定位”}

## 修复动作
{换件/处理/未修原因}

## 验收数据
{修复后复测读数；未修则写“—”}

## 复盘三问（复盘整理）
1. 判断对在哪：{ }
2. 绕了什么弯路：{ }
3. 下次先测什么：{ }

## 理论补卡
{本案一个知识点，大白话十句以内}
```
