# 维修案例复盘

## 一句话介绍

把一次主板维修的零散记录——口述、语音转写、随手笔记——整理成一张标准案例卡：还原检测路径、标出关键转折点、写复盘三问、补一张理论小卡，并沉淀成可以按故障类型回查的个人案例库。修完不白修，每块板都变成下一块板的老师。

## 它解决什么问题

自学维修的人常有这个循环：测了一下午、想明白了，特别有成就感；隔两周遇到同类故障，又从头摸一遍。问题不在手艺，在记录——当时的测点顺序、读数、判断转折，事后全凭记忆，记不住也查不回。

本技能把「记录」这件事做到顺手：用户只需要像平时一样把过程说出来，剩下的结构化、归档、回查都由技能完成。

## 核心功能

1. **口语成卡**：自然语言或语音转写直接变案例卡，缺失字段最多追问两句，问不到就标「未记录」，绝不编造读数。
2. **检测路径还原**：测点按真实顺序成表，档位、表笔极性、读数照原记录；走过的弯路也保留——那正是复盘的素材。
3. **关键转折点**：每张卡强制标出「哪一步读数让方向变了」，一张卡最值钱的就是这一行。
4. **复盘三问**：判断对在哪、绕了什么弯路、下次同类故障先测哪里——理论不在课本里补，在复盘里补。
5. **理论补卡**：每案只讲一个相关知识点，大白话＋生活类比，十句以内。
6. **案例库回查**：按现象分类和关键词调旧案；同类卡攒够 5 张，自动汇总一份「同类故障速查」。

## 设计理念

- **案例闯关式学习**：不先啃理论，用真实维修案例当关卡推进，每修好一块即时复盘成卡，成就感驱动下一步。
- **诚实记录**：读数照抄、缺失标记、归纳与原话分开呈现。案例库的可信度来自不美化。
- **教练式语气**：先肯定做对的推理，再谈弯路；复盘是帮学习者下次更快，不是判卷。

## 安全边界

只做记录整理与复盘教学，不替代实测、不远程指挥带电操作；涉及市电与电源一次侧只给安全规程提示；根因只做与已测读数一致的归纳，超出学习者当前阶段与工具范围的操作明确建议停手。

## 作者的话

作者是零基础自学主板维修的在读学习者，工作台上常驻一块万用表和七块练习板。这个技能最初就是给自己用的：第一关学测电压时就发现，光记「测对了」没用，得把每一次的路径和判断都留下来。希望它也能帮到同样在自学路上的人——你的每一块板，都值得一张卡。
